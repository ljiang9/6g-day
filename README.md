# 6g-day · 6G 的一天生活模拟器

> 概念致敬 2026 年"6G 网要来了"相关热搜报道中描绘的未来生活场景
> （全息会议、数字分身、太赫兹感知、AI 基站），所有剧情纯属虚构畅想，
> 如有雷同，说明 6G 真的来了。

## 玩法

你将体验"6G 时代的一天"，按时间线推进 6 个时段：

| 时段 | 场景 |
|---|---|
| 早晨 7:30 | 全息会议室：和千里之外的同事开会，你还穿着睡衣 |
| 上午 10:00 | 数字分身代会：三个会撞车，分身主动请缨 |
| 中午 12:30 | 无人机外卖：热气腾腾准时悬停，太赫兹感知什么都知道 |
| 下午 15:00 | AI 基站修网：光猫罢工，纳米机器人 3 分钟修好 |
| 晚上 20:00 | 虚拟世界探索：分身提议去赛博夜市探险 |
| 深夜 23:30 | AI 健康报告：基站"思考"一天，给你整了份个性化报告 |

每个时段 2–3 个选项（比如全息开会选"西装革履"还是"睡衣上阵"），影响三维属性：

- **效率值**：这一天你到底干成了多少事
- **社死值**：你的睡衣、分身和作息被多少人知道
- **电量**：全息设备耗电，记得充电

随机事件：全息卡顿 0.5 秒露出睡衣、太赫兹感知广播你点了双份外卖、
AI 基站过度"体贴"把你的作息发给了你妈。

一天结束按三维结算 4 档结局：**6G 原住民 / 赛博社死现场 / 赛博断电人 /
被 AI 安排得明明白白**，附善意玩梗评语。

## 运行

```bash
python3 -m sixg_day                        # 交互模式（需要终端）
python3 -m sixg_day --auto --games 10 --seed 42        # AI 随机演示 10 局
python3 -m sixg_day --auto --games 1 --seed 42 --verbose  # 打印全天战报
```

纯 Python 标准库（`argparse`/`random`/`sys`），Python 3.10+。

## 诚实局限

- 数值纯属拍脑袋调的，平衡性未经大规模仿真；AI 选择是纯随机，非策略
- 事件只有概率触发，无真正的因果链；文案池固定，多玩几局会眼熟
- 文本界面，无图形/存档；倒计时/实时交互无，纯回合制
- 6G 相关概念为 2026 年公开报道中的畅想，本项目不做任何技术断言
